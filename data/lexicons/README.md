# Loughran-McDonald Master Dictionary

`LM_MasterDictionary.csv` (~8.7MB) is gitignored — third-party data, not our own
work, and too large to be worth vendoring into the repo.

Download it yourself before running `scripts/compute_lm_scores.py`:

1. Go to https://sraf.nd.edu/loughranmcdonald-master-dictionary/
2. Download the CSV format link (currently `Loughran-McDonald_MasterDictionary_1993-2025.csv`,
   hosted on Google Drive)
3. Save it here as `data/lexicons/LM_MasterDictionary.csv`

Free for academic research use with attribution (see `REQUIREMENTS.md` §3.4).
